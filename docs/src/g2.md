# G₂ gauge fields

Gaugefields provides an explicit serial backend for four-dimensional G₂
gauge fields in the seven-dimensional fundamental representation. Select it
with `G2Backend()`; setting `colors=7` on another backend constructs SU(7) and
is not equivalent.

~~~julia
using Gaugefields

U = gauge_configuration(
    (4, 4, 4, 4);
    backend=G2Backend(),
    colors=7,
    halo=1,
    start=:hot,
    seed=1234,
)

@assert gauge_backend(U) isa G2Backend
@assert gauge_num_colors(U) == 7
println(measure_plaquette(U))
~~~

`start=:cold` creates identity links. `start=:hot` exponentiates random G₂
algebra elements with the backend's current scale, `0.2`; it is a convenient
random start, not a claim of exact Haar sampling. An explicit nonnegative
integer `seed` is reproducible and each of the four link directions receives a
different deterministic stream.

`gaussian_momenta(U; seed, sweep)` likewise provides reproducible G₂ algebra
momenta. Direction and sweep select separate StableRNG streams. Pass an
explicit seed when using a nonzero sweep counter.

## Representation and momentum

`G2Gaugefields_4D_wing` stores each link as a `7×7` `ComplexF64` matrix. Group
links are real orthogonal matrices preserving the chosen octonionic
three-form. `G2TA_Gaugefields_4D_serial` stores fourteen real coefficients per
site in an orthonormal G₂ Lie-algebra basis. The gauge force is projected
onto those fourteen directions rather than onto the SU(7) algebra.

The public algebra helpers include `g2_basis`, `g2_matrix`, `g2_coefficients`,
`project_to_g2`, `is_g2_algebra_matrix`, `g2_link_defects`, and `is_g2_link`.

## Current execution boundary

`G2Backend` currently supports:

- four dimensions and `colors=7`;
- `ComplexF64` link storage;
- serial execution, optionally expressed as `process_grid=(1,1,1,1)` and
  `comm=SerialCommunicator()`;
- periodic gauge-field boundaries;
- gauge-action evaluation, analytic force projection, and pure-gauge HMC.

It does not yet provide LatticeMatrices/JACC storage, MPI or GPU execution,
exact Haar hot starts, or a G₂-preserving HISQ smearing/projection force.
Fermion boundary phases belong to the Dirac operator and must not be described
as a G₂ center twist: G₂ has trivial center.

## Migration and validation

The G₂ implementation was rebased from the historical private v0.7.2 branch
onto Gaugefields v1.1.3 API base
`6d8eef2c913d60f7fd5782ff6421c1eb3d5024a5`. Validation covers the algebra,
link and momentum interfaces, group projection and update, gauge action,
finite-difference force, HMC reversibility/acceptance smoke tests, and the
high-level backend API.

On Julia 1.12.4, the full repository suite also reaches an unrelated pre-existing
bitwise SU(2) heatbath comparison failure in `su2update_allocationfree.jl`.
The same deterministic probe on the untouched v1.1.3 base and on the G₂
branch produces the same 766 mismatches and the same first differing bit, so it
is not a G₂ regression. Numerical G₂ tests pass independently.
